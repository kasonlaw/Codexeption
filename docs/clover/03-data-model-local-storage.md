## Goal

Introduce persistent data using SQLite and seed initial data.

---

## Requirements

- SQLite database
- ORM setup
- schema definitions
- seed script

---

## Tasks

1. Define schema:
   - UserProfile
   - WardrobeItem

   - WearHistory
2. Add DB client
3. Add seed data
4. Store local file paths for assets

---

- uploads
- segmentation
- AI generation

- seed script runs
